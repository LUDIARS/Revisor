# 台帳ありの非コード変更で登録検査を選択する

## 目的

AIFormat #1884で、ドメイン不要の設定変更が対象ドメイン不足としてテスト選択を停止した。
Revisorの分類・検査選択・通知の解釈を一致させる。

## 完了条件

- コードドメイン不要と明示された計画では、対象ドメインが空でも既存の登録検査計画を実行できる。
- コード変更や分類不明の古い計画の対象ドメイン欠落は拒否する。
- 既知ドメインのAugur実行、台帳なしの既存経路、検査失敗時のブロックを維持する。
- 通知は台帳ありの登録検査・実行不能を台帳未整備と区別する。
- Revisor審査・反映後にAIFormat #1884を再審査し、実行結果を確認する。

## スコープ

Revisorの審査計画、CI選択、審査報告と対応するspec・回帰テスト。
AIFormat台帳の削除やコード変更による迂回、履歴移行の再実行は含めない。
テスト実行・サービス操作は各運用規則に従う。
